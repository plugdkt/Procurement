# Procurement (ระบบประกาศจัดซื้อจัดจ้างและการจัดหาพัสดุ)

ระบบประกาศและติดตามสถานะโครงการจัดซื้อจัดจ้าง คณะวิทยาศาสตร์การแพทย์ มหาวิทยาลัยพะเยา

## คุณสมบัติเด่น (Features)
- จัดการแผนการจัดซื้อจัดจ้างประจำปี และโครงการจัดซื้อจัดจ้างย่อย
- ระบบติดตามสถานะโครงการ (Procurement Roadmap Tracking) ตามวิธี e-Bidding และวิธีเฉพาะเจาะจง
- รองรับการแบ่งงวดงาน การส่งมอบ การตรวจรับ และการเบิกจ่าย
- รายงานสรุปผลการดำเนินงานสำหรับผู้บริหาร (Executive Report)
- รองรับการเข้าสู่ระบบผ่าน UP LDAP / Active Directory และระบบผู้ใช้งานภายใน

## การติดตั้งและตั้งค่า (Installation & Configuration)
1. นำไฟล์ขึ้นเว็บเซิร์ฟเวอร์ (IIS / Apache / Nginx) ที่รองรับ PHP 7.4+ หรือ PHP 8.x
2. คัดลอกไฟล์ตั้งค่าฐานข้อมูล:
   ```bash
   cp config.example.php config.php
   ```
3. กำหนดค่าการเชื่อมต่อฐานข้อมูล MySQL ในไฟล์ `config.php`:
   ```php
   define('DB_HOST', 'localhost');
   define('DB_USER', 'your_db_user');
   define('DB_PASS', 'your_db_password');
   define('DB_NAME', 'procurement_db');
   ```
4. ระบบจะทำการตรวจสอบและสร้างตารางฐานข้อมูลที่จำเป็น (Auto Migration) ให้โดยอัตโนมัติเมื่อเปิดใช้งานครั้งแรก
